# Overview

Arcane Survival is a 2D game built with Unity and C#. In this game the can control a wizard who atacks with spells different enemies while earning points. Every 20 seconds the difficulty increases and each time there are more enemies which are faster

My main goal with this project is to improve my skills with game development with C#. This would include things like controling the input, player movement, game logic and the creation of other art

In order to play the file  `Assets/ArcaneSurvival/Scenes/ArcaneSurvival.unity` most be open the project in Unity 6

- WASD or arrow keys: Move the wizard.
- Left mouse button Hold - to cast spells toward the cursor.
- P or Escape - Pause or resume.
- Enter - Start a game or play again after game over.
- R: - Restart while paused or after game over.
- M - Mute or unmute sound effects.

# Development Environment

The project was created using Unity 6 and Visual Studio Code Editor. Gameplay (movements, game logic, menu interactions etc.) was created C# using a special library from game unity called Unity Engine. 

Note - Other elements like graphics and sounds were created using code with the help of an AI in order to be fully original and avoid using copies from other sources.
